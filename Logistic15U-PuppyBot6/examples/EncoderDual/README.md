# ทดสอบ Encoder สองตัว — รุ่นแก้ไขในเครื่อง 0.1.1-dev

เปิด `EncoderDual.ino` เลือกบอร์ด Logistic15U-PuppyBot6 แล้ว Verify
ตัวอย่างนี้เริ่มเฉพาะ Serial และ Encoder ไม่เริ่มมอเตอร์ เซอร์โว IMU หรือเซนเซอร์สี
ยังไม่ได้ทดสอบกับฮาร์ดแวร์จริง

ค่าขาที่สืบทอดจาก Library เดิมคือ Encoder 1 ใช้ GPIO 17/18 และ Encoder 2 ใช้
GPIO 19/20 ต้องตรวจเทียบกับการต่อสายจริง ไม่มีการกำหนดจำนวนพัลส์ต่อรอบใหม่

หลังตรวจสายและอัปโหลดเอง เปิด Serial Monitor ที่ 115200:

1. หมุน Encoder ตัวที่ 1: `E1` เปลี่ยน แต่ `E2` ควรคงเดิม
2. หมุน Encoder ตัวที่ 2: `E2` เปลี่ยน แต่ `E1` ควรคงเดิม
3. หมุนทั้งสองตัว: ทั้งสองค่านับต่อเนื่องได้
4. ส่ง `1`: รีเซ็ตเฉพาะ `E1`; ส่ง `2`: รีเซ็ตเฉพาะ `E2`
5. หลังรีเซ็ต หมุนแต่ละตัวอีกครั้งเพื่อตรวจว่าทั้งสองยังนับได้

## API

เมื่อ include `Logistic15U_PuppyBot6.h` สามารถเรียก API เดิมได้โดยตรง:

```cpp
init_encoders();                 // เริ่มทั้งสองตัว
int e1 = get_pulse_Encoder(1);
int e2 = get_pulse_Encoder(2);
resetEncoder(1);                 // รีเซ็ตเฉพาะตัวที่ 1
resetEncoder(2);                 // รีเซ็ตเฉพาะตัวที่ 2
```

`init_encoder(1)` และ `init_encoder(2)` ยังใช้ได้ การเรียกเริ่มต้นซ้ำไม่ล้างค่า
การอ่านหรือรีเซ็ตก่อน init จะเริ่มเฉพาะช่องที่เลือกก่อน หมายเลขนอกเหนือจาก 1/2
จะไม่เปลี่ยนช่องใด และการอ่านหมายเลขที่ไม่ถูกต้องคืน 0

PIO สองช่องนับสัญญาณพร้อมกัน แต่การอ่านสองค่าทาง CPU เป็นคนละคำสั่ง
ให้เรียก init/read/reset ของ Encoder จาก core เดียวกัน เช่น `setup()`/`loop()`
ไม่เรียก Encoder ตัวเดียวกันจาก `loop()` และ `loop1()` แข่งขันกัน
