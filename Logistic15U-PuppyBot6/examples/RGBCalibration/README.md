# สอบเทียบ RGB0 และ RGB1 ทั้ง 6 สี

1. เปิด `RGBCalibration.ino` และเลือกบอร์ด `Logistic15U-PuppyBot6` ตัวอย่างนี้เป็น Calibrate แบบ standalone; sketch ของผู้ใช้เข้า Calibrate ผ่านเมนู wait_SW1() แล้ว
2. อัปโหลดด้วย Arduino IDE จอ TFT แสดงเมนู `Sensor: RGB0` พร้อมค่า RGBC ดิบและค่าเฉลี่ยที่เคยเก็บ ใช้งานผ่านจอได้โดยไม่ต้องเปิด Serial Monitor
3. กด BOOT แล้วปล่อยเพื่อสลับ RGB0 กับ RGB1 แล้วกด SW1 แล้วปล่อยเพื่อเลือกเซนเซอร์ที่แสดง กดถัดไปมีเสียงสั้นโทนต่ำ ส่วนกดเลือกมีเสียงยาวกว่าโทนสูง
4. ในเมนูสี กด BOOT แล้วปล่อยเพื่อเลื่อนผ่าน Red, Green, Blue, Yellow, White, Black, Save all และ Sensor menu
5. เลื่อนมาที่ Red แล้ววางสีแดงหน้าเซนเซอร์ที่เลือก ใช้ระยะและมุมที่จะใช้งานจริง ให้แสงและ LED คงที่ จากนั้นกด SW1 แล้วปล่อยเพื่อเริ่มเก็บ
6. ถือสีให้นิ่งจนจอแสดง `Captured in RAM` และมีเสียงสำเร็จสองโน้ตไล่สูง การเก็บ 20 เฟรมใช้เวลาประมาณ 1.1 วินาที จอแสดงความคืบหน้าและเพิ่มเครื่องหมาย `+` ที่สีที่เก็บแล้ว กดค้างไม่ทำซ้ำ ทั้งสองปุ่มทำงานครั้งเดียวเมื่อปล่อย
7. กด BOOT ไปสีถัดไป เปลี่ยนวัตถุให้ตรงกับสีบนจอ แล้วกด SW1 แล้วปล่อยเพื่อเก็บ ทำจนครบทั้ง 6 สี ระหว่างเก็บปุ่มจะไม่เปลี่ยนรายการ
8. เลื่อนไป `Save all` แล้วกด SW1 แล้วปล่อยเพื่อบันทึกข้อมูลทั้งสองเซนเซอร์ลง Flash จอแสดง `Saved to flash` และ `FLASH` เมื่อบันทึกสำเร็จ เปิดเครื่องใหม่แล้วโปรแกรมโหลดค่ากลับมา บันทึกเพียงบางสีก่อนได้
9. เลื่อนไป `Sensor menu` แล้วกด SW1 แล้วปล่อยเพื่อกลับไปเลือกเซนเซอร์ กด BOOT เพื่อเปลี่ยนเซนเซอร์แล้วกด SW1 เพื่อเลือก เมนูเริ่มที่ Red เมื่อเปลี่ยนเซนเซอร์ ทำซ้ำจนครบทั้งสองตัวและบันทึกอีกครั้ง

`RAM*` หมายถึงมีค่าที่ยังไม่บันทึก จอแสดง `6/6` แยกแต่ละเซนเซอร์เมื่อเก็บครบ หากจอแสดง `Offline` ให้ตรวจสายแล้วกด SW1 แล้วปล่อยเพื่อเก็บสีเดิมอีกครั้ง การยกเลิกหรือเก็บไม่ครบไม่ทับค่าชุดเดิม

หากใช้ Serial Monitor ให้ตั้ง 115200 baud ส่ง `0` หรือ `1` เพื่อเลือกเซนเซอร์ และ `r g b y w k` เพื่อเลือกแดง เขียว น้ำเงิน เหลือง ขาว ดำ จากนั้นส่ง `c` เพื่อเก็บ ค่าเลือกจาก Serial ใช้ร่วมกับเมนู SW1 ได้ ส่ง `s` เพื่อบันทึก `p` เพื่อส่งออก CSV, `x` เพื่อยกเลิก หรือ `?` เพื่อดูคำสั่ง ส่ง `l` เพื่อโหลดจาก Flash อีกครั้ง คำสั่งนี้ทิ้งค่าที่ยังไม่บันทึกเมื่อโหลดสำเร็จ

ตัวอย่างอ่าน RGB0 และ RGB1 ใน `loop1()` ส่วน Serial, TFT และงานสอบเทียบอยู่ใน `loop()` ค่า LIVE เป็นข้อมูลล่าสุดของเซนเซอร์ที่เลือก ค่า MEAN เป็นค่าเฉลี่ยของชุดที่เก็บเสร็จแล้ว ไม่มีข้อมูลสอบเทียบสมมติใส่มาให้

หลังเก็บครบ ให้ลองวัดสีเดิมซ้ำโดยยังไม่กด SW1 แล้วเปรียบเทียบ LIVE กับ MEAN และช่วง min/max ใน CSV ตรวจค่าที่ค้างอยู่ที่เพดานการอ่านของเซนเซอร์ด้วย สอบเทียบใหม่เมื่อเปลี่ยนระยะ แสง LED, gain หรือ integration time

ดู [API และรูปแบบข้อมูล](API.md) สำหรับนำค่าที่เก็บไปใช้ต่อ โหมดนี้ยังไม่ตัดสินชื่อสีอัตโนมัติ และต้องตรวจผลกับสีจริงก่อนกำหนดเกณฑ์แยกสี

รุ่น 0.1.11-dev ใช้ 50.4 ms / Gain 4× ข้อมูล v1 จาก 2.4 ms ต้องเก็บใหม่ก่อนใช้ข้อมูล v2 หากเก็บไม่ผ่าน จอแสดง RGB zero: retry, Clear <10: retry หรือ Saturated: retry พร้อมค้างค่าที่ถูกปฏิเสธในช่อง FAIL คงค่าชุดเดิมและไม่ส่งเสียงเก็บสำเร็จ เรียก updateRGB() ต่อเนื่องใน loop1 เพื่อให้ IMU ทำงานได้ระหว่างรอเก็บแสง ข้อมูล v2 ที่บันทึกด้วย 0.1.7-dev ยังโหลดใช้ได้

ปุ่มทั้งสองใช้ debounce 30 ms กดค้างก่อนเข้าเมนูต้องปล่อยแล้วกดใหม่ กดสองปุ่มซ้อนกันจะไม่รับคำสั่งจนปล่อยทั้งคู่ บรรทัดล่างบน TFT แสดง BOOT next SW1 OK

BOOT อ่านผ่าน BOOTSEL ของ core อย่างถี่สุดทุก 20 ms เฉพาะเมนูที่ไม่ได้เก็บสี ไม่อ่านในโหมด Show การอ่านหยุดอีก core ชั่วคราว จึงอาจขัดจังหวะ IMU ระหว่างใช้เมนู ต้องทดสอบกับปุ่ม BOOT บนบอร์ดจริง รูปแบบ Flash v2 เดิมและค่าที่ Save จาก 0.1.9-dev หรือ 0.1.10-dev ยังใช้ได้
